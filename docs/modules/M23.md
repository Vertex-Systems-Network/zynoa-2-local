    ## Goal

    Protect chat history, managed files, projects, memory, user preferences and recoverable agent state across crashes, releases and reinstalls.

    ## Integration responsibilities

    Shared GUI and persistent state must be implemented first. M23 uses native Tauri-Rust core for privileged operations, typed events, SQLite transaction journal, policy-controlled workers, stable error codes, diagnostics, and versioned backend contracts. The React UI never rewrites critical paths or performs backups from untrusted frontend context. Important events survive abrupt process exits. For details and failure/rollback semantics, read the detailed system contract above before modifying code.
