    ## Goal

    Allow user to choose and migrate storage paths for model runtimes, downloaded optional modules, user data, managed assets and backups without silently losing files.

    ## Integration responsibilities

    Shared GUI and persistent state must be implemented first. M24 uses native Tauri-Rust core for privileged operations, typed events, SQLite transaction journal, policy-controlled workers, stable error codes, diagnostics, and versioned backend contracts. The React UI never rewrites critical paths or performs backups from untrusted frontend context. Important events survive abrupt process exits. For details and failure/rollback semantics, read the detailed system contract above before modifying code.
