    ## Goal

    Present signed GitHub releases as user-controlled update notifications with safe download, verification, pre-update checkpoints and recovery.

    ## Integration responsibilities

    Shared GUI and persistent state must be implemented first. M25 uses native Tauri-Rust core for privileged operations, typed events, SQLite transaction journal, policy-controlled workers, stable error codes, diagnostics, and versioned backend contracts. The React UI never rewrites critical paths or performs backups from untrusted frontend context. Important events survive abrupt process exits. For details and failure/rollback semantics, read the detailed system contract above before modifying code.

    ## API design requirements

    Implement `getStatus`, `getPreferences`, `updatePreferences`, `validate`, `startJob`, `pauseJob`, `resumeJob`, `getJob`, `getHistory`, `cancelJob`, and `getDiagnostics` where applicable with exact capability-scoped names. Each operation has versioned request and response, `idempotencyKey`, correlation ID, progress updates, permission boundary, stable error codes and accessible UI feedback. Detailed data types, job transitions, and event contracts are defined in the source of truth. No 'success' state without verified persistence and outcome.

    ## Mandatory pre-dev and testing

    Follow PRE-DEV check and source verification; enumerate risks/alternative approaches; write unit/contract/integration/E2E/negative/recovery tests before marking complete. Verify actual behavior under offline, canceled task, process crash, corrupt data, storage full, permission denied, Unicode filenames, session resume, release migration, and interrupted jobs. For active product, capture annotated real screenshots for each option and screen; add Help links and Wiki source. A green local doc validator is not evidence of functional application correctness.

    ## Phase signoff

    Complete only if feature is usable end-to-end, relevant data persists on reboot, error messages lead to real recovery, access controls pass, all warnings triaged, performance measured, all control screenshots genuinely captured, Wiki/Help links resolve, signed release and other related gates pass where appropriate, and PR merged SHA verified.
