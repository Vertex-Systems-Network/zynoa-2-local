## Quick start in the Windows desktop preview

Open **Workbench** with Ctrl+5, **Components** with Ctrl+6, **Preferences** with Ctrl+2, and the bundled offline Help Center with F1. Ctrl+Shift+P opens the local navigation-only command palette; type a view name, use Up/Down and Enter, or Esc to cancel. Native startup/read-only handshake is not proof that project creation or canvas editing is enabled; those controls remain unavailable.

## Practical workflows

**Gallery button states (T02.06):** Ctrl+6 → select Primary action or Secondary → observe the `aria-pressed` selection checkmark and polite status update. Type in the sample input; choosing an action must not overwrite the typed value. The disabled button does nothing; Ready/Pending/Offline/Error chips are only style demonstrations, not real system health.

**Narrow desktop layout (T02.07):** Resize the Tauri window toward its 900px minimum. The gallery becomes one column at widths up to 950px, metrics and status text wrap, and cards/input remain accessible without horizontal clipping. In Workbench, use arrow keys on the tablist to select Layout controls, then the keyboard slider to preview left/right pane widths.

**Themes/density (M02-OPT-01/02):** Ctrl+2 → choose values from the Appearance and Navigation density selects. They update the current app window but are **not persisted**; a new launch restores the defaults.

**Focus/accessibility:** Navigate via Tab and arrow keys; focus outline appears for keyboard focus. Fixed Ctrl+1…6 shortcuts switch views. F1 opens the shipped offline Help Center, whose bundled articles are separate from this unreleased Wiki source.

## Troubleshooting and limitations

- No matching command? Clear the search; there is no online command provider or arbitrary code execution.
- Focus ring missing? Use keyboard Tab rather than click; inspect the active Tauri window.
- Theme reset? Session state is intentionally not saved.
- Project creation, real canvas, backup restore, properties-panel density and shortcut reassignment are unimplemented. Don't use disabled controls as evidence of functioning workflows.
- Remote Wiki deployment, complete offline Help source mapping, final screenshot approvals, and final module/phase merge remain pending. No automatic remote telemetry/user data upload is enabled.
