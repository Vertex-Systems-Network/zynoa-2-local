## Common workflows

- **Component Gallery (T02.06):** Ctrl+6 → select Primary/Secondary → observe selected styling and accessible feedback. Typing in the sample field is independent; disabled controls do nothing. Status chips are examples, not live health.
- **Responsive layout (T02.07):** Resize the Tauri window to its 900px minimum → inspect one-column gallery, wrapping metrics and cards; use Workbench (Ctrl+5) Layout controls to adjust the 25–65% split preview by keyboard.
- **Unavailable native services:** Project creation and file editing are disabled in P02; UI previews never imply real workspace data was saved.
