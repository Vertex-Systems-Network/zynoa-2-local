## Summary

Runtime host, app lifecycle, settings, IPC and reliable local persistence.

## Getting started

In the unsigned P01 Windows build, use the sidebar or `Ctrl+1`–`Ctrl+4` to open Overview, Settings, Recovery and Diagnostics. Overview shows startup and read-only native transport state. Workspace creation, persistent preferences, backup/restore, an in-app Help route and released installers are still unavailable. See the Help source for the tested subset; actual user-action screenshots remain unaccepted.

## Common workflows

- Verify the native startup status and read-only workspace handshake in Overview.
- Inspect disabled preference and location choices in Settings without assuming they save changes.
- Review Recovery's no-backups state; do not treat the placeholder as a functioning restore flow.
- Read Diagnostics as a non-live capability summary, not an incident log.
