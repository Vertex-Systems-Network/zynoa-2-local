## Rootless Docker syntax-only gateway — pre-release technical source

The [P00 Docker Syntax Broker](../../operations/P00_DOCKER_SYNTAX_BROKER.md) implements a default-disabled Docker adapter that can compile a small model-generated Python fixture **inside** a trusted rootless container, never executing candidate bytecode or writing actual source/user files. [ADR-0015](../../adr/0015-rootless-syntax-gate.md) explains digest pinning, no network/mounts, Docker identity checks and why rootless+cgroup reports still require independent host testing. The broker also rejects a correctly formatted but **unapproved** image digest before invoking Docker; only the explicitly reviewed image reference is permitted. A routine image update requires a reviewed allowlist change and new tests, plus separate host provenance/isolation proof. Mocked Linux/Windows unit tests are not deployment evidence. This is versioned **Wiki source**, not published GitHub Wiki, and has no application screenshots.

## Effective in-container resource checks (P00 source, no published Wiki)

The rootless syntax-only broker now requires container-visible cgroup-v2 memory/PIDs/CPU ceilings at or below the configured limits and a read-only root with only loopback networking before attempting to compile candidate Python. An ignored cgroup setting or missing controller denies the operation. Host-owned unit tests and mocked Docker receipts do **not** attest real OS enforcement; Issue #3 remains the blocker for a deployed Linux test host, runtime probes, confidential credentials and full worker lifecycle. [Operator contract](../../operations/P00_DOCKER_SYNTAX_BROKER.md).

## P00 no-overwrite worktree fixture writer (unpublished source)
