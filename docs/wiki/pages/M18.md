## Getting started

Open the app and find this feature under the shared navigation (once phase P01 is delivered). Use local Help for offline steps. The final article must include user-action screenshots, actual option defaults and tested keyboard paths.

## Common workflows

- Open an existing project and inspect module prerequisites.
- Perform a minimal task and inspect the result and activity history.
- Use undo/cancel/retry as supported; record errors in Diagnostics.
