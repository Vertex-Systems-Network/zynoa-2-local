## Verified P01 bounded local diagnostic foundation (2026-11-22)

Tauri records fixed local categories for boot, denied IPC and sanitized Rust panic, in a bounded append-only native spool. The Diagnostics desktop view is only a capabilities summary, **not** an incident viewer, remote issue uploader or privacy approval interface. No raw error message, file path, prompt or secret is accepted by the bounded event API. Screenshot obligations for missing controls remain pending. ## Summary

Crash/error detection, safe grouping, queued reports and GitHub issue tracking.

## Getting started

Open the P01 desktop's **Diagnostics** summary (`Ctrl+4`) to inspect the declared native event capability and disabled remote reporting. It does not display live logs, incident IDs, reports or issue links. All option controls below are planned.

## Common workflows

- Open Diagnostics and read its local-capability summary.
- Confirm remote reporting remains disabled.
- Use disposable Windows CI diagnostic tests for developer triage; the GUI has no incident list.
