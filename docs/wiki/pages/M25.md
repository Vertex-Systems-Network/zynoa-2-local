## P02 shared UI — source implementation, native review pending

Open **Update Center** from System navigation or the command palette. Search screen names or option IDs. Tab to a screen and press Enter; the heading receives focus. Tab to the option or its explanation. Reset session drafts clears temporary choices. F1 opens the bundled guide. Native connection status grants no operation authority. No production P11 service is enabled.

- **M25-S01 — Update Center Overview:** Development foundation; no availability or published version inferred.
- **M25-S02 — New Update Notification:** No verified release received; no reminder or notification scheduled.
- **M25-S03 — Update Release Notes:** Only a signed verified release can have installable release notes.
- **M25-S04 — Download & Installation Progress:** Download, signature verification and pre-update checkpoint must precede installation.
- **M25-S05 — Update History & Recovery:** No installation history or rollback target fabricated.
- **M25-S06 — Update Preferences:** Session-only preferences are not applied to an updater or OS notification service.
- **M25-S07 — Update Failure Troubleshooting:** Do not install unsigned artifacts or delete data. Preserve actual recovery checkpoints.
