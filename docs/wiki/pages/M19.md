## Troubleshooting and privacy boundaries

Available issues: native bridge unavailable, no article results, keyboard navigation trouble, workspace/backup unavailable. Each issue has three deterministic recovery steps, Prev/Next/Solved controls, linked offline articles and local report preparation if all steps fail. No action executes a native repair command or reads project files.

The local report contains only an article ID, reason, module and catalog version. User-supplied notes, credentials, screenshots, file paths and telemetry are not uploaded. Remote tickets require separately reviewed infrastructure; no publication or background reporting is claimed.
