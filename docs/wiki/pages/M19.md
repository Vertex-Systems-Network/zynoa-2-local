## Troubleshooting and privacy boundaries

Available issues: native bridge unavailable, no article results, keyboard navigation trouble, workspace/backup unavailable. Each issue has three deterministic recovery steps, Prev/Next/Solved controls, linked offline articles and local report preparation if all steps fail. No action executes a native repair command or reads project files.

The local report contains only an article ID, reason, module and catalog version. User-supplied notes, credentials, screenshots, file paths and telemetry are not uploaded. Remote tickets require separately reviewed infrastructure; no publication or background reporting is claimed.

## Open offline Help directly from the global command palette (P02 source)
Ctrl+Shift+P now discovers Help articles and M02/M19 option references alongside view commands. Search local titles, article content, curated keywords or a fixed option ID. Select a result with the keyboard or click it to open the bundled article/option without leaving the app. The option reference switches to the selected item with the module and query filters cleared. Unknown or external destinations cannot be injected into the allowlisted search inventory.

The feature uses local read-only indexes, twenty-result caps, session-only React navigation and no network, browser persistence or hosted Wiki dependency. The existing F1 contextual Help, FAQ, guided tour, recovery wizard and Wiki source checker remain separate workflows. **Native Windows and accessibility acceptance pending.**

## Keyboard focus on directly opened option reference (P02)

When Ctrl+Shift+P opens an option by its exact ID, the app now scrolls its real selected option detail into view and focuses its semantic heading after closing the command dialog. The option-detail region is labelled by that heading. Keyboard and assistive-technology users can immediately identify the selected item, its default, limitations and recovery without having to search the Help list again. Selecting an unrelated workflow or leaving Help cancels pending focus requests; focus is not saved or reported remotely. Windows UI Automation evidence and final screen-reader acceptance remain separate gates.
