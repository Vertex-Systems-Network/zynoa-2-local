## Summary

Fast streaming local conversation with files, tools and durable history.

## Getting started

Open Chat from the shared navigation. Create or select a conversation, refresh the fixed-loopback Ollama inventory, choose an installed model and context budget, inspect the estimate, then Send. Stop is available during an active turn and Retry creates a separate attempt. Use bundled Help offline. Final T15 user-action screenshots and hosted publication remain pending.

## Common workflows

- Create or reopen a durable local conversation.
- Choose an installed model for that thread and inspect its context budget.
- Send a prompt, watch ordered local deltas, Stop if needed, and use Retry turn without overwriting earlier history.
- Refresh history after runtime errors; user messages are committed before inference begins.
