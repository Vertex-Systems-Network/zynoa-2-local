## Verified P01 native-only security foundation (2026-11-22)

A Rust Windows Credential Manager adapter, sanitized secret errors and deny-first native capability checks passed Windows tests. The WebView has no API to read/write credentials. This is **not** a production-signed installer, a permission grant screen or a complete Security Center; the planned option controls and screenshots remain pending. [Native security CI](https://github.com/Vertex-Systems-Network/zynoa-2-local/actions/runs/44973840898).

Read [the detailed Help source](../../help/articles/M17.md) for implementation status; the options below are planned, not released. There are no verified real screenshots or published Wiki pages yet.

## Summary

Independent native policy enforcement and transparent local-first privacy.

## Getting started

No Security Center navigation or credential-management screen exists in the P01 GUI. Windows CI validates the native Rust security boundary and credential adapter. **Settings** (`Ctrl+2`) does not save permissions or user preferences. All options below remain planned.

## Common workflows

- Check the native startup indicator; security capability tests are developer-only CI evidence.
- Confirm Settings preferences are disabled and cannot grant permissions.
- Do not treat planned secrets or audit controls as available user workflows.
