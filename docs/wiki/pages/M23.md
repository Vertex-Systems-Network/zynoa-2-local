## P02 shared UI — illustrated preview

Open **Backup Center** from System navigation or the command palette. Search screen names or option IDs. Tab to a screen and press Enter; the heading receives focus. Tab to the option or its explanation. Reset session drafts clears temporary choices. F1 opens the bundled guide. Native connection status grants no operation authority. No production P03 service is enabled.

- **M23-S01 — Data & Privacy Overview:** Native vault foundation exists; no authorized chat or managed-file inventory is exposed.
- **M23-S02 — Chat History Browser:** No chat records are exposed. A native handshake does not prove committed conversations.
- **M23-S03 — Backup Dashboard:** Review backup planning and pre-update protection; no snapshot has been created here.
- **M23-S04 — Create Backup Wizard:** Choose intended coverage, frequency and retention; native destination and encryption remain unavailable.
- **M23-S05 — Backup History & Verification:** A backup is not restorable until manifest and integrity checks are independently verified.
- **M23-S06 — Restore Preview:** Plan restoration into a new profile; never overwrite the only copy.
- **M23-S07 — Restore Progress & Results:** No progress percentage, completed record or audit entry is fabricated.
- **M23-S08 — Data Export/Import:** Portable exports and import validation require typed authorization and data-integrity checks.
- **M23-S09 — Recovery Mode:** Do not delete the vault. Verified compatible recovery source required.

- **M23-OPT-01 — Auto-save acknowledged chats:** Chat transaction acknowledgement belongs to P03; no chat state is claimed.
- **M23-OPT-02 — Select backup categories:** Draft coverage only; external originals, secrets and caches are excluded unless explicitly authorized. Draft choices: Chats, projects and managed files; Chats and settings; Managed files only.
- **M23-OPT-03 — Choose backup destination:** Native independent-disk validation and destination picker required; no path is collected.
- **M23-OPT-04 — Enable scheduled backups:** Session scheduling intention only; no scheduler is enabled.
- **M23-OPT-05 — Backup frequency & retention:** Session retention plan; no files are pruned. Draft choices: Daily · keep 7; Weekly · keep 4; Monthly · keep 3.
- **M23-OPT-06 — Encrypt backup with passphrase:** Verified encrypted backup service required. Do not enter a passphrase.
- **M23-OPT-07 — Create backup now:** No authorized backup job endpoint; no snapshot is created.
- **M23-OPT-08 — Verify existing backup:** Verified backup catalog and checksum reader required.
- **M23-OPT-09 — Restore to new profile:** Compatible backup and isolated new-profile restore required.
- **M23-OPT-10 — Selective restore or merge:** Draft restore strategy; no record is merged or overwritten. Draft choices: New profile only; Selective restore preview.
- **M23-OPT-11 — Export chat history:** No authorized conversation export; no chat data is read.
- **M23-OPT-12 — Export all managed files:** No authorized managed-file export; no file is copied.
- **M23-OPT-13 — Open managed data folder:** No approved native folder-open command; paths are not exposed.
- **M23-OPT-14 — Include external project files (explicit):** Explicit inclusion intention only; no external path is requested or copied.
- **M23-OPT-15 — Protect before update:** Pre-update protection intention; no checkpoint is created.
- **M23-OPT-16 — View restore audit & logs:** No authorized restore audit query; no private event is exposed.
- **M23-OPT-17 — Data retention & deletion policy:** Draft retention preference; no deletion. Draft choices: Keep until explicitly deleted; Review retention before deletion.
- **M23-OPT-18 — Recovery key assistance:** No recovery key workflow; keep secrets outside this interface.
