## P02 shared UI — illustrated preview

Open **Data Locations** from System navigation or the command palette. Search screen names or option IDs. Tab to a screen and press Enter; the heading receives focus. Tab to the option or its explanation. Reset session drafts clears temporary choices. F1 opens the bundled guide. Native connection status grants no operation authority. No production P05 service is enabled.

- **M24-S01 — Storage Overview:** Native location registry foundation exists. No storage paths, byte counts or free-space measurements exposed.
- **M24-S02 — Custom Download Locations:** Runtime paths require native owner validation. No path entry or picker is active.
- **M24-S03 — Model Storage Manager:** Managed and external models have different ownership. Do not delete unidentified files.
- **M24-S04 — Installed Runtime Locations:** Externally installed runtimes must not be treated as app-managed.
- **M24-S05 — Relocation Wizard:** Inventory, free-space check, quiesce and staged validation must precede an actual move.
- **M24-S06 — Relocation Progress & Recovery:** Original copy remains authoritative until verified activation and rollback checkpoint exist.
- **M24-S07 — Cleanup & Quotas:** Quota preference is a draft. No deletion or free-space claim.
- **M24-S08 — Storage Diagnostics:** Native path disclosure requires explicitly authorized endpoint.

- **M24-OPT-01 — Browse current locations:** Read-only native registry exists but no frontend path inventory endpoint is authorized.
- **M24-OPT-02 — Set Ollama model path:** Ollama path changes require ownership detection and runtime-aware restart.
- **M24-OPT-03 — Set Hugging Face cache path:** Hugging Face cache needs validated per-process adapter configuration.
- **M24-OPT-04 — Set llama.cpp GGUF path:** GGUF movement needs managed inventory and checksum validation.
- **M24-OPT-05 — Set ComfyUI models path:** ComfyUI needs compatible runtime adapter configuration.
- **M24-OPT-06 — Set optional module install root:** Managed runtime root needs native ownership and installer compatibility checks.
- **M24-OPT-07 — Set user data location (advanced):** Vault relocation requires recoverable transaction and verified original copy.
- **M24-OPT-08 — Set backup destination:** Native destination selection requires independent-storage checks.
- **M24-OPT-09 — Set download staging location:** Staging changes require volume and resumable-download validation.
- **M24-OPT-10 — Choose move vs new-downloads-only:** Draft move policy; no existing file or future download location is changed. Draft choices: New downloads only; Move existing after verification.
- **M24-OPT-11 — Pause and resume relocation:** No active relocation job; pause and resume unavailable.
- **M24-OPT-12 — Verify moved files by checksum:** No native inventory or staged move for checksum verification.
- **M24-OPT-13 — Rollback failed relocation:** No relocation transaction or rollback receipt.
- **M24-OPT-14 — Storage free-space warning:** Free-space measurement requires authorized native query.
- **M24-OPT-15 — Set per-category storage quotas:** Draft quota only; no limit enforced. Draft choices: No draft limit; 25 GB; 100 GB; 250 GB.
- **M24-OPT-16 — Cleanup unused models safely:** No verified ownership or unused-model inventory; deletion denied.
