## Quick start

1. Open Help Center in the sidebar or press **F1** from a desktop view to open contextual Help.
2. Choose **Articles & search** to search the bundled catalog; change the category or open a related guide. Search length is limited to 120 characters.
3. Choose **Troubleshooting wizard** for native bridge, missing article, keyboard or unavailable workspace recovery. Press **This fixed it** or **Still stuck — next step**, with Previous/Start over available.
4. Choose **FAQ & glossary** for keyboard-expandable questions and linked offline articles.
5. Choose **Wiki & link checker** to view the **source-controlled** M02/M19 Wiki Markdown mapping, validate a local `help://article/<id>` reference, and check internal links. This does not contact or publish a remote Wiki.
6. When an article is inaccurate, select **Prepare local report**, choose a reason, and copy its safe JSON. The app **does not** transmit it.

The offline catalog publishes typed **schema 1** and **version `2026.11-p02`**. Unsupported schema/catalog versions and malformed requests are refused with `M19-SCHEMA-001`, `M19-CATALOG-409` and `M19-QUERY-400`. These are local validation messages, not network failures.

## Troubleshooting and recovery

- **Native bridge unavailable:** Verify actual Windows app vs browser preview, restart only the window, then read local Diagnostics; do not delete application data.
- **No Help results:** Clear filters, search known terms and check the catalog version.
- **Keyboard confusion:** Expand sidebar via Alt+N; reset Ctrl+1–6 mappings from Workbench Keyboard guide. F1 and Ctrl+Shift+P remain reserved.
- **Workspace or backup disabled:** The UI foundation is not a usable editor. Avoid typing project content into previews; do not treat native handshake as saved work.

All wizard steps are informational and reversible; no native repair command is executed. Finishing the steps does not claim an incident has been resolved automatically.

## Privacy, versioning and limitations

The offline route parser allows only `help://article/[a-z0-9-]` known article IDs. No `file://`, `https://`, traversal, query or fragment handling occurs in the offline resolver. Broken links are reported locally as not found. The catalog validator checks article IDs, related references, wizard/FAQ destinations and source-only Wiki mappings.

**No search or report data is stored in browser storage, sent as telemetry, or uploaded to GitHub.** Copy uses the browser/native clipboard permission; a selectable read-only field is the fallback.

**Final release gate:** complete functional state coverage, independent native screen review, all 14 M19 final PNGs with alt text, and published Wiki verification where required. This source guide and the UI must not be called fully released until those gates pass.

## Open offline Help directly from the global command palette (P02 source)
Ctrl+Shift+P now discovers Help articles and M02/M19 option references alongside view commands. Search local titles, article content, curated keywords or a fixed option ID. Select a result with the keyboard or click it to open the bundled article/option without leaving the app. The option reference switches to the selected item with the module and query filters cleared. Unknown or external destinations cannot be injected into the allowlisted search inventory.

The feature uses local read-only indexes, twenty-result caps, session-only React navigation and no network, browser persistence or hosted Wiki dependency.
