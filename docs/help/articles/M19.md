# M19 — Offline Help Center: working user guide

**Phase:** P02, source-controlled preview (not released)  
**Scope:** Local article search, contextual guidance, a step-by-step troubleshooting wizard, FAQ/glossary, source-only Wiki reference mapping and local sanitized article reports.  
**Network/privacy:** Search, wizard, FAQ and routes work from the desktop bundle. No account, cloud query, automatic GitHub ticket or local search-history persistence. A remote Wiki has **not** been synced/published.  
**Final visual evidence:** All 6 M19 screen and 8 M19 option PNG entries remain **PENDING** in the final screenshot manifest. Working source/CI and candidate native images are not final release screenshots.

## Quick start

1. Open Help Center in the sidebar or press **F1** from a desktop view to open contextual Help.
2. Choose **Articles & search** to search the bundled catalog; change the category or open a related guide. Search length is limited to 120 characters.
3. Choose **Troubleshooting wizard** for native bridge, missing article, keyboard or unavailable workspace recovery. Press **This fixed it** or **Still stuck — next step**, with Previous/Start over available.
4. Choose **FAQ & glossary** for keyboard-expandable questions and linked offline articles.
5. Choose **Wiki & link checker** to view the **source-controlled** M02/M19 Wiki Markdown mapping, validate a local `help://article/<id>` reference, and check internal links. This does not contact or publish a remote Wiki.
6. When an article is inaccurate, select **Prepare local report**, choose a reason, and copy its safe JSON. The app **does not** transmit it.

The offline catalog publishes typed **schema 1** and **version `2026.11-p02`**. Unsupported schema/catalog versions and malformed requests are refused with `M19-SCHEMA-001`, `M19-CATALOG-409` and `M19-QUERY-400`. These are local validation messages, not network failures.

**Implemented:** Search field defaults empty, category defaults All topics, max query length 120. Search is local, case-insensitive, weighted by title/keywords and deterministic. The typed contract accepts a result limit of 1–50; UI uses 50. No result state offers Clear filters. **Undo:** clear query/category; no persistence. **Screenshot:** `../../screenshots/M19/M19-OPT-01.png` — PENDING.

### M19-OPT-05 — Browse FAQ

**Partially implemented:** Wiki & link checker displays source mappings for M02 and M19 and opens their **related local offline guides**. ### M19-OPT-07 — Report broken article
**Implemented locally only:** In the article reader or after exhausting wizard suggestions, Prepare local report opens a reason selector (Outdated instructions by default; Broken reference; Unreadable article), read-only safe JSON and Copy locally button. The report contains schema, M19 ID, catalog version, article ID and allowlisted reason, `transmitted:false`. Clipboard denied? Select and copy the text manually. **Not implemented:** remote ticket creation, attachment upload or automatic diagnostics forwarding. **Screenshot:** `../../screenshots/M19/M19-OPT-07.png` — PENDING.

### M19-OPT-08 — Offline help mode
**Implemented as the default architecture**, not as a persisted on/off setting: articles, search, FAQs, wizard and local route checks ship in the app and never query cloud services. The status shows the bundled article count/version. A hosted Wiki is not part of the offline bundle. **Screenshot:** `../../screenshots/M19/M19-OPT-08.png` — PENDING.

## Troubleshooting and recovery

- **Native bridge unavailable:** Verify actual Windows app vs browser preview, restart only the window, then read local Diagnostics; do not delete application data.
- **No Help results:** Clear filters, search known terms and check the catalog version.
- **Keyboard confusion:** Expand sidebar via Alt+N; reset Ctrl+1–6 mappings from Workbench Keyboard guide. F1 and Ctrl+Shift+P remain reserved.
- **Workspace or backup disabled:** The UI foundation is not a usable editor. Avoid typing project content into previews; do not treat native handshake as saved work.

All wizard steps are informational and reversible; no native repair command is executed. Finishing the steps does not claim an incident has been resolved automatically.

## Privacy, versioning and limitations

The offline route parser allows only `help://article/[a-z0-9-]` known article IDs. No `file://`, `https://`, traversal, query or fragment handling occurs in the offline resolver. Broken links are reported locally as not found. The catalog validator checks article IDs, related references, wizard/FAQ destinations and source-only Wiki mappings.

**No search or report data is stored in browser storage, sent as telemetry, or uploaded to GitHub.** Copy uses the browser/native clipboard permission; a selectable read-only field is the fallback.

**Final release gate:** complete functional state coverage, independent native screen review, all 14 M19 final PNGs with alt text, and published Wiki verification where required. This source guide and the UI must not be called fully released until those gates pass.

## Five-step offline guided tour

Select **Guided tour** inside Help to learn Overview, Workbench, interface preferences, bundled Help and feature availability. Next lesson and Previous lesson operate a real session-scoped step index; Finish guided tour displays completion and Restart tour returns to the first lesson. Each step links to a real local article. Tab/Space/Enter work on native buttons. No native commands execute on behalf of the user, no guided screenshot overlays are fabricated, and no progress is stored or uploaded. ## In-app option reference — all sixteen M02/M19 IDs

Open Help → **Option reference** for 8 M02 and 8 M19 documented options. Filter by module or search text, select any option, and read its default, steps, limitations and recovery. **Read full bundled guide** resolves an existing local Help article; a route such as `help://option/M02-OPT-02` can be validated and selected in the *local route checker* without opening a network service. Unknown IDs, traversal strings, extra URL parameters and external schemes fail closed. Search max 100 characters; changes are ephemeral. The option route is **not** an OS-level registered URI protocol, and no native preference, project, Wiki or ticket is written by browsing it. The twelve-article bundle and existing Help modes remain available.

**Availability labels are specific:** session means an interactive window-scoped preference, preview-only means an illustrative component (not a native project operation), built-in is a fixed bundled behavior, and partial indicates missing screenshot-hotspot or remote Wiki features. Real Windows visual captures, screen-reader E2E and final per-option screenshot artifacts are pending before P02 T08/T10 acceptance.
