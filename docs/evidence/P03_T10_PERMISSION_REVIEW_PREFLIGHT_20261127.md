## First implementation slice — ingress guard

Inspection of `model_gateway.rs` found that unrequested structured tool calls could be ignored and a mixed text/tool frame could be marked complete. The existing text-only adapter sends no tools; deny nonempty or malformed structured calls before delta publication or terminal success. Missing, null or empty call arrays represent no call. Reject explicit function calls and tool-result roles too. Reuse the existing sanitized response fault and partial-failure semantics; do not persist raw call arguments or enable any action. Tests exercise plain text/empty arrays, structured calls with text and terminal success, malformed arrays and unsupported function calls. This is a prerequisite to the review contract, not the review contract itself. No new UI, grant or migration. Official API reference already recorded in ADR-0030: https://docs.ollama.com/api/chat .
