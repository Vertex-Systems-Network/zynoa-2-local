| P04 | Project artifact snapshots and external files reference semantics | Uncontrolled copies or missing recovery proof |
| P05 | M24 completed Ollama/HF/ComfyUI location adapters and safe move-existing workflows | Failed move causes only-copy loss; runtime does not start after move |
| P06–P10 | All new research, design, media and agent artifacts respect vault/recovery and user-selected locations | Module saves untracked files or cannot recover interrupted tasks |
| P11 | M20 signed CI publisher + M25 complete actual updater/install/notification, full migration gates | Silent user-data loss, unsigned update or wrong-channel delivery |
| P12 | Cloud backup optional & encrypted; multi-platform update/storage adapters | Mandatory proprietary paid dependency introduced |

## v3.2 — Changelog / documentation gate applied to EVERY phase

- **P00:** adopt M26 event model, change records schema, action gate and independent audit vs shipped logs contract; compare release tool alternatives.
- **P01:** implement durable append-only `change_events`, idempotency and error-to-change correlation; preserve after crash and backup.
- **P02:** finish integrated What's New / Known Issues / Version History / Module Changes UI, real state rendering, a11y and contextual Help design; active data source may remain planned until P11 publisher.
- **P03–P10:** every change in that module must have change record, issue/PR links where applicable, updated module docs, actual UI screenshot when completed, Wiki/help source and tests.
- **P11:** derive release feed, `CHANGELOG.md` and GitHub Release notes from signed verified manifest; verify identical versions/IDs and in-app offline cache. Test no early release claims.
- **P12:** preserve semantic version changes across plugin capabilities and platform updates.

**PR gate:** no affected module can become COMPLETED_VERIFIED if change record/docs/help/wiki/screenshot and CI evidence incomplete. A new reported issue is logged immediately but never described as fixed before release. See [M26 system contract](operations/CHANGE_INTELLIGENCE_CHANGELOG.md).
